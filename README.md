# Trust the Process

A Chrome extension that **soft-blocks Gmail** so you reach for your agents instead of your inbox.

<p align="center">
  <img src="docs/demo.gif" alt="Typing mail.google.com opens a full-screen overlay that says Trust the process, Use your agents, with shortcuts to Chat, Calendar, Meet, Drive and Admin, and an Open email anyway button that asks how long you need." width="560">
</p>

When you open `mail.google.com`, a full-screen overlay says **Trust the process — Use your agents**. It offers one-click shortcuts to the Google apps you still need (Chat, Calendar, Meet, Drive, Admin) and a deliberately quiet **Open email anyway** button for the times you really have to go in.

It's a nudge, not a lock. Nothing is deleted or hidden from you, and you can always get through.

## Features

- Full-screen overlay on Gmail, opaque from the first frame so the inbox doesn't flash
- Shortcuts to Chat, Calendar, Meet, Drive and Admin, opened on the same Google account (`/u/N/`) you were on. Press `1`–`5` to jump straight to one
- **Open email anyway** asks you to pick a time window (5 / 15 / 30 minutes by default). When it ends, the overlay comes back in every Gmail tab
- Gmail's keyboard shortcuts are blocked while the overlay is up, so stray keys can't act on the inbox behind it
- Optionally block only specific accounts (e.g. your work address) and leave personal Gmail alone
- Custom headline and subtitle, shortcuts you can turn on or off, and custom snooze durations
- Light and dark mode, follows your system
- No network requests and no tracking. See [PRIVACY.md](PRIVACY.md)

## Install

### From source (developer mode)

1. Clone or [download](https://github.com/nemerkab/trust-the-process/archive/refs/heads/main.zip) this repository:
   ```sh
   git clone https://github.com/nemerkab/trust-the-process.git
   ```
2. Open `chrome://extensions` in Chrome (or any Chromium browser: Edge, Brave, Arc).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
5. The settings page opens. Optionally add your work address under **Which accounts?**

Click the toolbar icon at any time to change settings.

## Settings

| Setting | Default | Notes |
| --- | --- | --- |
| Blocking is on | On | Master switch |
| Email addresses to block | *(empty)* | Empty blocks every Gmail account. With addresses listed, other accounts briefly show the overlay while the extension reads the account from the tab title, then it disappears |
| Headline / Subtitle | Trust the process / Use your agents | |
| Shortcuts | All on | Chat, Calendar, Meet, Drive, Admin |
| Open email anyway durations | 5, 15, 30 | Minutes, comma separated |

## How it works

- `src/content.js` runs on `mail.google.com` at `document_start` and mounts the overlay in a closed Shadow DOM, so Gmail's styles can't leak in and the overlay's styles can't leak out. A `MutationObserver` puts it back if Gmail rebuilds the page.
- Settings live in `chrome.storage.sync`. The "open anyway" window lives in `chrome.storage.local`. Every Gmail tab listens for changes, so snoozing or re-blocking applies everywhere at once.
- Account filtering reads the address from Gmail's tab title (`Inbox - you@company.com - Gmail`). If no address shows up within 15 seconds, the overlay stays on.

```
manifest.json        Manifest V3
src/content.js       Overlay (injected into Gmail)
src/settings.js      Defaults and storage helpers shared by content + options
src/options.*        Settings page
src/background.js    Toolbar click opens settings
icons/               Generated by scripts/make_icons.py
scripts/package.sh   Builds a Chrome Web Store zip into dist/
```

## Development

No build step. Edit the files, then hit the reload icon on the extension card in `chrome://extensions` and refresh Gmail.

- Regenerate icons: `pip install pillow && python3 scripts/make_icons.py`
- Package for the Chrome Web Store: `./scripts/package.sh` → `dist/trust-the-process-<version>.zip`
